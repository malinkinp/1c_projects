# Домашнее задание: Печатные формы (Табличный документ)

Выгрузка из самописной конфигурации в рамках обучающего курса.




## Оптимизация запроса в `АктВыполненыхРабот.МодульМенеджера`

Текущий запрос планируется разделить на пакет со следующей структурой:

1. **запрос**: получение данных из документа без разыменования полей и их запись во временную таблицу (`ВТ_Документ`).
2. **запрос**: соединение `ВТ_Документ` с табличной частью справочника Организация.
3. **запрос**: получение строк из табличной части документа и вызов метода `ВыполнитьПакет()`.
